# Oficina
Oficina de desenvolvimento — Projetos e soluções

## Projetos

| Pasta | O que é |
| ----- | ------- |
| [`alo/`](alo/) | Sala de conversa aberta: entra com um apelido e fala em tempo real. Usa o Supabase. |
| [`britagem/`](britagem/) | PWA de relatório de turno da britagem: paradas, detector de metal e leituras. |
| [`agenda-telefonica/`](agenda-telefonica/) | PWA de agenda: busca, ficha e discagem offline. Vem vazio; a lista é carregada no aparelho. |
| [`alarme-gps/`](alarme-gps/) | PWA que toca um alarme ao chegar perto de um ponto marcado no mapa. |
| [`escola/`](escola/) | App de treino, para mexer no código sem risco de quebrar os outros. |
| [`caderno-pencil/`](caderno-pencil/) | PWA para escrever à mão com a Apple Pencil no iPad e copiar o texto digitado. |
| [`camera-negativo/`](camera-negativo/) | Câmera fotográfica que mostra e fotografa com as cores invertidas. |
| [`ura-ios/`](ura-ios/) | PWA para consultar e treinar as Instruções Operacionais da URA, offline. |
| [`inicio/`](inicio/) | Tela inicial (launcher) para Android com cara de Pixel Nexo: abas de fichário, comando, gaveta, foco e os apps de verdade. |
| [`treino/`](treino/) | Ficha de academia Puxa & Empurra: esteira, máquinas, cargas e descanso. |
| [`mensagem-efemera/`](mensagem-efemera/) | Texto vira imagem preta e branca para enviar como visualização única. |
| [`descubra-seu-app/`](descubra-seu-app/) | Questionário que indica ao cliente o app ideal. |
| [`portfolio/`](portfolio/) | Portfólio para apresentar a agências e empresas. |
| [`dd-logos/`](dd-logos/) | Logomarcas e paleta da marca DD Desenvolvedor Digital. |
| [`karla-neves/`](karla-neves/) | Site da Karla Neves Estética. |
| [`lete-diedrichs/`](lete-diedrichs/) | Site da artista Lete Diedrichs. |
| [`harmonize/`](harmonize/) | Guia do projeto Harmonize Clinical. |

`.github/workflows/pages.yml`. A primeira execução liga o Pages sozinha — não é
